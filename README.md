# MNSU SE Program Robot Project

*Welcome to Minnesota State University, Mankato's Software Engineering program's joint project!*

Rather than use a conventional messaging software, our director proposed that we bring messages to and from pre-planned locations using a robotic vehicle connected to a web application interface.
